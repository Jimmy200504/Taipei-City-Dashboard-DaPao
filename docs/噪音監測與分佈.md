# 環境噪音監測與分佈

## 資料

### 資料來源

本組件整合臺北市與新北市兩個縣市的噪音監測站資料，資料類型分為「交通噪音」與「環境噪音」，監測方式分為「人工監測」與「自動監測」。

| 城市               | 來源                                                                                                                                           | 格式                        | 主要欄位                                                     | 用途                               |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------- | ------------------------------------------------------------ | ---------------------------------- |
| 臺北市             | 臺北市環保局噪音品質查詢 `https://www.tldep.gov.taipei/Public/DetInformation/NoiseQuality.aspx`                                                | HTML 表格（需網頁爬取）     | 測站名稱、測站編號、管制區別、月份、日間/晚間/夜間分貝值     | 臺北市測站月份量測值               |
| 新北市             | 新北市環保局噪音監測統計 `https://www.epd.ntpc.gov.tw/IntegratedContentCenter/noisestats?categoryId=6ca80917-078a-4bd6-8a54-f67cb75d8d80`      | PDF 年報（需 PDF 解析）     | 測站名稱、測站編號、管制區別、月份、日/晚/夜分貝值、音量標準 | 新北市測站月份量測值               |
| 新北市（測站地址） | 新北市環保局人工測站 `https://www.epd.ntpc.gov.tw/StaticPage/manual-stations`、自動測站 `https://www.epd.ntpc.gov.tw/StaticPage/auto-stations` | HTML 靜態頁面（需網頁爬取） | 測站名稱、地址                                               | 新北市測站地址，供地理編碼取得座標 |

兩個資料來源皆無公開 API，ETL 需透過網頁爬取（臺北市）或 PDF 解析（新北市）取得資料，並在 Airflow DAG 中每月觸發，更新最新一個月的量測資料。

#### 測站編號命名規則（以新北市為例）

```text
0401020TN003
│││││││││└── 流水號（測站序號）
│││││││└──── 噪音類別（TN = 交通噪音 Traffic Noise / EN = 環境噪音 Environmental Noise）
││└──────── 年份或類別流水
└────────── 行政區代碼
```

| 噪音類別 | 管制區別 | 日間 (dB) | 晚間 (dB) | 夜間 (dB) |
| -------- | -------- | --------- | --------- | --------- |
| 交通噪音 | 二       | 71        | 69        | 63        |
| 交通噪音 | 三       | 74        | 70        | 67        |
| 交通噪音 | 四       | 76        | 75        | 72        |
| 環境噪音 | 一       | 55        | 50        | 45        |
| 環境噪音 | 二       | 55        | 50        | 45        |
| 環境噪音 | 三       | 60        | 55        | 50        |
| 環境噪音 | 四       | 65        | 60        | 55        |
| 環境噪音 | 五       | 75        | 70        | 65        |

### 欄位解讀

#### 量測值

每個測站每月產生三個時段分貝值：

| 欄位                 | 說明                      |
| -------------------- | ------------------------- |
| 日間（`day_db`）     | 白天量測均能音量，單位 dB |
| 晚間（`evening_db`） | 傍晚量測均能音量，單位 dB |
| 夜間（`night_db`）   | 夜間量測均能音量，單位 dB |

量測值含以下特殊標記，ETL 需辨別處理：

| 原始符號 | 意義                  | ETL 處理                                   |
| -------- | --------------------- | ------------------------------------------ |
| `-`      | 當月未量測或資料缺漏  | 存為 `NULL`，設 `quality_flag = 'missing'` |
| `*`      | 量測值超過音量標準    | 存入數值，設 `exceeded_standard = true`    |
| `#`      | 上傳至環境部的測站    | 保留到 `upload_flag` 欄位                  |
| `&`      | 上傳至 SIP 系統的測站 | 保留到 `upload_flag` 欄位                  |

#### 季別換算

量測資料為月份粒度，前端折線圖以季為單位，ETL 需在聚合表儲存季別欄位：

| 季別 | 月份                |
| ---- | ------------------- |
| Q1   | 1 月、2 月、3 月    |
| Q2   | 4 月、5 月、6 月    |
| Q3   | 7 月、8 月、9 月    |
| Q4   | 10 月、11 月、12 月 |

## 前端

### 前端儀表板

前端儀表板支援 `臺北市` 與 `雙北` 城市範圍切換，以及 `交通噪音` 與 `環境噪音` 監測類別切換。

| 組件 index             | query type  | chart type                | 說明                                                    |
| ---------------------- | ----------- | ------------------------- | ------------------------------------------------------- |
| `env_noise_trend`      | `time`      | `TimelineSeparateChart`   | 3 條折線：日間／晚間／夜間均能音量季度趨勢              |
| `env_noise_district`   | `two_d`     | `BarChart`                | 行政區日間均能音量，最新一季，由高到低排列              |
| `env_noise_exceed`     | `two_d`     | `DistrictChart`, `BarChart` | 行政區超標站數，最新一季，可切換地圖或長條圖顯示      |
| `env_noise_monitoring` | `map_legend` | `MapLegend`              | 測站點位地圖，顏色依日間均能音量分 5 級                 |

每個組件均支援 `臺北市`（`city = 'taipei'`）與 `雙北`（`city = 'metrotaipei'`）切換。折線圖 y_axis 固定為「日間」、「晚間」、「夜間」三條線，x 軸為各季第一天的 timestamp。

### 前端地圖圖層

地圖以噪音測站為點位，點的顏色依最新一季日間均能音量深淺顯示。

**顏色分級**（依日間均能音量）：

| 等級 | 分貝範圍 | 顏色說明 |
| ---- | -------- | -------- |
| 低   | < 55 dB  | 綠色     |
| 中低 | 55–65 dB | 黃綠色   |
| 中   | 65–70 dB | 黃色     |
| 中高 | 70–75 dB | 橙色     |
| 高   | ≥ 75 dB  | 紅色     |

切換 `臺北市` 時只顯示臺北市測站；切換 `雙北` 時同時顯示臺北市與新北市測站。

點擊測站後，彈跳資訊顯示：

- 測站名稱：`station_name`
- 城市與行政區：`city`、`district`
- 測站編號：`station_id`
- 噪音類別：交通噪音 / 環境噪音（`noise_category`）
- 監測方式：人工 / 自動（`monitoring_type`）
- 管制區別：`control_zone`
- 管制標準（日/晚/夜）：`standard_day_db`、`standard_evening_db`、`standard_night_db`
- 最新量測值（日/晚/夜）：`latest_day_db`、`latest_evening_db`、`latest_night_db`
- 歷年超標次數：`total_exceed_count`
- 資料來源：`source_name`

地圖資料使用 WGS84/EPSG:4326 點位。若測站座標缺漏，該站不得進入地圖圖層，但仍可在行政區統計中保留（以行政區中心點代替）。

## 後端

後端需提供前端儀表板與地圖圖層兩類資料：季別聚合折線圖資料、行政區彙整資料與測站點位資料。

### 噪音季度趨勢（`env_noise_trend`）

`query_type = 'time'`，x 軸為各季第一天的 timestamp，y_axis 為中文時段，跨所有噪音類別 AVG 聚合成 3 條線。

**臺北市（`city = 'taipei'`）**

```sql
SELECT
  MAKE_DATE(year, (quarter-1)*3+1, 1)::timestamp AS x_axis,
  CASE period WHEN 'day' THEN '日間' WHEN 'evening' THEN '晚間' ELSE '夜間' END AS y_axis,
  ROUND(AVG(avg_db)::numeric, 1) AS data
FROM env_noise_quarterly_stats_tpe
WHERE year >= EXTRACT(YEAR FROM NOW())::int - 2
GROUP BY year, quarter, period
ORDER BY year, quarter, period
```

**雙北（`city = 'metrotaipei'`）**

```sql
SELECT
  MAKE_DATE(year, (quarter-1)*3+1, 1)::timestamp AS x_axis,
  CASE period WHEN 'day' THEN '日間' WHEN 'evening' THEN '晚間' ELSE '夜間' END AS y_axis,
  ROUND(AVG(avg_db)::numeric, 1) AS data
FROM (
  SELECT year, quarter, period, avg_db
  FROM env_noise_quarterly_stats_tpe
  WHERE year >= EXTRACT(YEAR FROM NOW())::int - 2
  UNION ALL
  SELECT year, quarter, period, avg_db
  FROM env_noise_quarterly_stats_new_tpe
  WHERE year >= EXTRACT(YEAR FROM NOW())::int - 2
) combined
GROUP BY year, quarter, period
ORDER BY year, quarter, period
```

### 行政區噪音分佈（`env_noise_district`）

`query_type = 'two_d'`，取最新一季，跨所有噪音類別 AVG 後由高到低排列。

**臺北市（`city = 'taipei'`）**

```sql
SELECT
  district   AS x_axis,
  ROUND(AVG(avg_day_db)::numeric, 1) AS data
FROM env_noise_district_summary_tpe
WHERE (year, quarter) = (
  SELECT year, quarter FROM env_noise_district_summary_tpe
  ORDER BY year DESC, quarter DESC LIMIT 1
)
GROUP BY district
ORDER BY data DESC
```

**雙北（`city = 'metrotaipei'`）**

```sql
SELECT
  district   AS x_axis,
  ROUND(AVG(avg_day_db)::numeric, 1) AS data
FROM (
  SELECT district, avg_day_db, year, quarter
  FROM env_noise_district_summary_tpe
  UNION ALL
  SELECT district, avg_day_db, year, quarter
  FROM env_noise_district_summary_new_tpe
) combined
WHERE (year, quarter) = (
  SELECT year, quarter FROM (
    SELECT year, quarter FROM env_noise_district_summary_tpe
    UNION ALL
    SELECT year, quarter FROM env_noise_district_summary_new_tpe
  ) all_q ORDER BY year DESC, quarter DESC LIMIT 1
)
GROUP BY district
ORDER BY data DESC
```

### 行政區噪音超標次數（`env_noise_exceed`）

`query_type = 'two_d'`，取最新一季，`exceed_count` 為該行政區內超標站數（任一時段 avg_db 超過管制標準即算超標）。

**臺北市（`city = 'taipei'`）**

```sql
SELECT
  district          AS x_axis,
  exceed_count::int AS data
FROM env_noise_district_summary_tpe
WHERE (year, quarter) = (
  SELECT year, quarter FROM env_noise_district_summary_tpe
  ORDER BY year DESC, quarter DESC LIMIT 1
)
ORDER BY data DESC
```

**雙北（`city = 'metrotaipei'`）**

```sql
SELECT
  district          AS x_axis,
  exceed_count::int AS data
FROM (
  SELECT district, exceed_count, year, quarter
  FROM env_noise_district_summary_tpe
  UNION ALL
  SELECT district, exceed_count, year, quarter
  FROM env_noise_district_summary_new_tpe
) combined
WHERE (year, quarter) = (
  SELECT year, quarter FROM (
    SELECT year, quarter FROM env_noise_district_summary_tpe
    UNION ALL
    SELECT year, quarter FROM env_noise_district_summary_new_tpe
  ) all_q ORDER BY year DESC, quarter DESC LIMIT 1
)
GROUP BY district, exceed_count
ORDER BY data DESC
```

### 環境噪音監測與分佈（`env_noise_monitoring`）

`query_type = 'map_legend'`，僅回傳圖例色階項目；實際測站點位由前端讀取靜態 GeoJSON 檔。

```sql
SELECT unnest(array['< 55 dB','55-65 dB','65-70 dB','70-75 dB','> 75 dB']) AS name,
       'circle' AS type
```

GeoJSON 靜態檔位於 `Taipei-City-Dashboard-FE/public/mapData/`：

| 城市範圍 | 檔案                                 | 測站數 |
| -------- | ------------------------------------ | ------ |
| 臺北市   | `env_noise_monitoring.geojson`       | 23 站  |
| 雙北     | `env_noise_monitoring_metro.geojson` | 49 站  |

`component_maps` 對應：臺北市用 `index = 'env_noise_monitoring'`，雙北用 `index = 'env_noise_monitoring_metro'`（兩者 id 均動態取得，非硬編碼）。

### ETL 座標處理

原始資料（臺北市網頁與新北市 PDF）均不包含測站精確座標，ETL 需在首次匯入時進行地理編碼：

1. 新北市測站地址可另爬取以下兩頁取得，優先於地理編碼 API：
   - 人工測站：`https://www.epd.ntpc.gov.tw/StaticPage/manual-stations`
   - 自動測站：`https://www.epd.ntpc.gov.tw/StaticPage/auto-stations`
2. 取得地址後，以測站名稱或地址搭配城市名稱查詢地理編碼 API（如 TGOS 或 HERE）。
3. 地理編碼失敗時，以行政區中心點作為暫代座標，並設 `geocode_quality = 'district_centroid'`。
4. 座標確認後，人工維護 `env_noise_stations` 的 `wkb_geometry` 欄位，不在每次 ETL 中覆寫已有座標。
5. 缺漏座標的測站排除地圖圖層，但保留行政區統計。

### 資料更新與 metadata

ETL 每次更新後需同步更新 `dataset_info`。`env_noise_stations` 支援地圖圖層，`dataset_info` 的 geometry 類型標記為 `Point`，座標系統為 `EPSG:4326`。月份明細表與聚合表不需 geometry，但需保留資料來源、更新頻率、資料時間與 ETL 說明。

### ETL 難點與處理策略

| 難點                  | 說明                          | 建議策略                                                                                           |
| --------------------- | ----------------------------- | -------------------------------------------------------------------------------------------------- |
| 臺北市資料無 API      | 網頁顯示 HTML 表格，需爬取    | 使用 `requests` + `BeautifulSoup` 解析，設 User-Agent 與 Retry 機制                                |
| 新北市資料為 PDF      | 每年一份年報 PDF，需 PDF 解析 | 使用 `pdfplumber` 解析表格，以測站編號與月份作為 key                                               |
| 新北市 PDF 僅提供年報 | 資料滯後約一年                | ETL 每年初更新前一年完整資料；監控官方是否提供更即時 Open Data                                     |
| PDF 表格跨欄複雜      | 含合併儲存格與多層表頭        | pdfplumber bbox 定位逐表解析，設置 header 對應規則                                                 |
| 量測值含特殊符號      | `*`（超標）、`-`（缺漏）      | ETL 以 regex 清除符號後轉 float，另設 exceeded / missing flag                                      |
| 測站無精確座標        | 僅有名稱（路名或地名）        | 新北市先爬取人工／自動測站頁取得地址，再地理編碼；臺北市直接以測站名稱地理編碼；座標入庫後不再覆寫 |

## AI Chat 的結合方法

AI Chat 透過後端 tool calling 整合本組件，不直接讓前端呼叫資料庫。建議提供以下 tools：

| Tool                         | 參數                                                                 | 回傳                                   | 用途                                   |
| ---------------------------- | -------------------------------------------------------------------- | -------------------------------------- | -------------------------------------- |
| `get_noise_summary`          | `city_scope`, `noise_category`, `year`                               | 測站數、平均分貝、超標率、最新資料季度 | 回答整體噪音水平概況                   |
| `get_noise_quarterly_trend`  | `city_scope`, `noise_category`, `year_range`                         | 各季日間/晚間/夜間均能音量             | 供 AI 解釋折線圖趨勢                   |
| `get_noise_district_ranking` | `city_scope`, `noise_category`, `year`, `quarter`                    | 行政區均能音量與超標率排名             | 供 AI 解釋行政區熱度圖                 |
| `get_noise_station_detail`   | `station_id`                                                         | 測站基本資訊、歷月量測值、超標記錄     | 供地圖點擊或使用者詢問單站資訊         |
| `set_noise_view`（未實作）   | `city_scope`, `noise_category`, `focus_district`, `focus_station_id` | 前端視圖控制指令                       | 讓 AI 協助切換城市範圍、類別或聚焦測站 |

Tool 參數規則：

- `city_scope` 只允許 `taipei` 或 `metrotaipei`。
- `noise_category` 只允許 `traffic` 或 `environmental`。
- `district` 使用行政區中文名稱；未指定時代表全部行政區。
- `station_id` 必須是測站編號格式（如 `0401020TN003`）。
- `year_range` 為整數陣列（如 `[2023, 2024, 2025]`）；未指定時預設最近三年。

AI 回答需附帶資料時間與資料來源，並在資料缺漏時明確說明限制。座標以地理編碼取得，部分測站精準度較低。

## 部署順序

### 首次部署

```bash
# Step 1  建立 dashboard DB 資料表
docker cp db-sample-data/noise-monitoring-tables.sql postgres-data:/tmp/noise-monitoring-tables.sql
docker exec postgres-data psql -U postgres -d dashboard -f /tmp/noise-monitoring-tables.sql

# Step 2  套用 dashboardmanager 元件與 Dashboard 設定
docker cp db-sample-data/noise-monitoring-component.sql postgres-manager:/tmp/noise-monitoring-component.sql
docker exec postgres-manager psql -U postgres -d dashboardmanager -f /tmp/noise-monitoring-component.sql

docker cp db-sample-data/noise-monitoring-dashboard.sql postgres-manager:/tmp/noise-monitoring-dashboard.sql
docker exec postgres-manager psql -U postgres -d dashboardmanager -f /tmp/noise-monitoring-dashboard.sql
```

### 重新部署（schema 有變更時）

```bash
# 先清除 dashboard DB 資料表
docker exec postgres-data psql -U postgres -d dashboard -c \
  "DROP TABLE IF EXISTS env_noise_stations, env_noise_monthly_measurements,
   env_noise_quarterly_stats_tpe, env_noise_quarterly_stats_new_tpe,
   env_noise_district_summary_tpe, env_noise_district_summary_new_tpe CASCADE;"
```

然後重新執行首次部署的 Step 1–2。`noise-monitoring-dashboard.sql` 已包含清除舊 `query_charts` 的邏輯，重跑 Step 2 即可確保資料正確。

### 執行 ETL

```bash
# Step 3  執行臺北市噪音 ETL
docker exec develop-airflow-webserver-1 airflow dags unpause proj_city_dashboard_D990101
docker exec develop-airflow-webserver-1 airflow dags trigger proj_city_dashboard_D990101
# 等待約 1 分鐘，確認 etl task=success：
docker exec develop-airflow-webserver-1 airflow dags list-runs \
  -d proj_city_dashboard_D990101 --no-backfill 2>&1 | grep manual | head -3

# Step 4  執行新北市噪音 ETL（可與 Step 3 同時觸發，PDF 解析約需 3 分鐘）
docker exec develop-airflow-webserver-1 airflow dags unpause proj_city_dashboard_D990102
docker exec develop-airflow-webserver-1 airflow dags trigger proj_city_dashboard_D990102
# 等待約 3 分鐘，確認 etl task=success：
docker exec develop-airflow-webserver-1 airflow dags list-runs \
  -d proj_city_dashboard_D990102 --no-backfill 2>&1 | grep manual | head -3

# Step 5  執行噪音聚合（Step 3、4 的 etl task 均 success 後）
docker exec develop-airflow-webserver-1 airflow dags unpause proj_city_dashboard_D990103
docker exec develop-airflow-webserver-1 airflow dags trigger proj_city_dashboard_D990103
# 等待約 1 分鐘，確認 etl task=success：
docker exec develop-airflow-webserver-1 airflow dags list-runs \
  -d proj_city_dashboard_D990103 --no-backfill 2>&1 | grep manual | head -3
```

> **注意**：三支 DAG 的整體執行狀態會顯示 `failed`，這是因為 `update_dataset_info` task 找不到 `dataset_info` 表（測試環境未建立）。只需確認 `etl` task 本身為 `success` 即可，資料已正確寫入。

## 驗證清單

| 項目                   | 驗證指令 / 方式                                                                                      |
| ---------------------- | ---------------------------------------------------------------------------------------------------- |
| 臺北市測站筆數         | `SELECT COUNT(*) FROM env_noise_stations WHERE city='臺北市';` 預期 23                              |
| 新北市測站筆數         | `SELECT COUNT(*) FROM env_noise_stations WHERE city='新北市';` 預期 27                              |
| 臺北市季度統計         | `SELECT COUNT(*) FROM env_noise_quarterly_stats_tpe;` 預期 ~360 筆                                  |
| 新北市季度統計         | `SELECT COUNT(*) FROM env_noise_quarterly_stats_new_tpe;` 預期 ~687 筆                              |
| 臺北市行政區彙整       | `SELECT COUNT(*) FROM env_noise_district_summary_tpe;` 預期 ~75 筆                                  |
| 新北市行政區彙整       | `SELECT COUNT(*) FROM env_noise_district_summary_new_tpe;` 預期 ~115 筆                             |
| 最新資料季度（臺北）   | `SELECT year, quarter FROM env_noise_quarterly_stats_tpe ORDER BY year DESC, quarter DESC LIMIT 1;` |
| 最新資料季度（新北）   | `SELECT year, quarter FROM env_noise_quarterly_stats_new_tpe ORDER BY year DESC, quarter DESC LIMIT 1;` |
| query_charts 筆數      | `SELECT index, city FROM query_charts WHERE index LIKE 'env_noise%' ORDER BY index, city;` 預期 8 筆 |
| 前端折線圖             | 切換臺北市／雙北，顯示日間／晚間／夜間 3 條折線，x 軸為季度日期                                     |
| 前端行政區分佈         | 各行政區橫向長條圖，由高到低排列，數值為日間均能音量                                                 |
| 前端超標次數           | 行政區超標站數長條圖，可切換行政圖與橫向長條圖                                                       |
| 前端地圖               | 測站點位顯示，顏色依 dB 分 5 級，右側圖例正確顯示色階                                               |
