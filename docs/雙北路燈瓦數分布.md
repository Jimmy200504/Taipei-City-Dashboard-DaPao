## 2. 瓦數等級定義

每根燈桿的 `watt` = 所有燈具瓦數加總（臺北市：各燈種瓦數之和；新北市：單一 `power` 欄位）。

| `watt_bucket` | `watt_bucket_order` | `level`（GeoJSON 欄位值） | 條件 |
|---------------|---------------------|--------------------------|------|
| `ultra_low` | 1 | `1-ultra_low` | watt ≤ 30 |
| `low` | 2 | `2-low` | 31 ≤ watt ≤ 80 |
| `medium` | 3 | `3-medium` | 81 ≤ watt ≤ 150 |
| `high` | 4 | `4-high` | 151 ≤ watt ≤ 250 |
| `very_high` | 5 | `5-very_high` | watt > 250 |

**無效記錄處理**：watt 欄位清理後結果為 0 → **整筆刪除**，不進資料庫。

### 等級顏色

| `level` | 顏色 | Hex |
|---------|------|-----|
| `1-ultra_low` | 藍 | `#2196F3` |
| `2-low` | 青 | `#00BCD4` |
| `3-medium` | 黃 | `#FFEB3B` |
| `4-high` | 橘 | `#FF9800` |
| `5-very_high` | 紅 | `#F44336` |

## 3. 資料來源

| 城市 | 資料集頁面 | 原始資料格式 | 更新頻率 |
|------|-----------|------------|---------|
| 臺北市 | [臺北市路燈資產清冊](https://data.taipei/dataset/detail?id=262e80cf-579c-4bfb-ba73-31621bc84616) | 靜態 JSON（`TaipeiLight.json`） | 不定期 |
| 新北市 | [新北市路燈資料](https://data.ntpc.gov.tw/datasets/39149fe0-85ab-4e6c-99e5-60657d44895f) | 分頁 API（page/size） | 每週 |

### 臺北市欄位解讀

一筆記錄 = 一根燈桿。座標為 TWD97（EPSG:3826），需轉 WGS84（EPSG:4326）。

| 原始欄位 | 用途 |
|---------|------|
| `SerialNumber` | 路燈編號（對應 `serial_no`，來源有重複，不設 PK） |
| `Dist` | 行政區（無「區」字尾，ETL 補上後寫入，例如「信義」→「信義區」） |
| `Quantity` | 燈數量（僅一種燈具時使用） |
| `LightKind1`–`LightKind5` | 燈種（第 2–5 可空） |
| `LightWatt1`–`LightWatt5` | 各燈種瓦數字串，需清理 |
| `LightHeight` | 燈桿高度（m） |
| `LightYear` | 裝設年分（存入 assets 表，不輸出至 GeoJSON） |
| `TWD97X` / `TWD97Y` | TWD97 座標 |

**watt 計算邏輯（臺北市）：**
- 僅 `LightKind1` 有值：`watt = parse(LightWatt1) × Quantity`
- 多種燈具：`watt = sum(parse(LightWatt1..5))`（各種數量不明，不乘）
- `parse()` = 以 regex `[^\d.]` 替換為空字串後轉 float，失敗視為 0

### 新北市欄位解讀

一筆記錄 = 一盞路燈。座標已為 WGS84，直接使用。

| 原始欄位 | 用途 |
|---------|------|
| `seqno` | 路燈序號（對應 `serial_no`，來源有重複，不設 PK） |
| `town` | 行政區（已含「區」字尾） |
| `power` | 瓦數字串；可能為逗號分隔多燈值（如 `130,130`），需逐段解析後**加總** |
| `longitude` / `latitude` | WGS84 座標 |

#### `query_charts`（4 筆）

**Component A — taipei：**

```sql
SELECT district AS x_axis, ROUND(avg_watt)::int AS data
FROM env_streetlight_district_summary
WHERE city_scope = 'taipei'
ORDER BY avg_watt DESC
```

`query_type=two_d`, `map_config_ids={}`, `city=taipei`, `time_from=static`

**Component A — metrotaipei：**

同上，`WHERE city_scope = 'metrotaipei'`, `city=metrotaipei`

**Component B — taipei：**

```sql
SELECT d.district AS x_axis,
       CASE b.watt_bucket
         WHEN 'ultra_low' THEN '≤30W'
         WHEN 'low'       THEN '31-80W'
         WHEN 'medium'    THEN '81-150W'
         WHEN 'high'      THEN '151-250W'
         WHEN 'very_high' THEN '>250W'
       END AS y_axis,
       COALESCE(w.lamp_count, 0) AS data
FROM (SELECT DISTINCT district FROM env_streetlight_district_watt_bucket WHERE city_scope = 'taipei') d
CROSS JOIN (SELECT DISTINCT watt_bucket, watt_bucket_order FROM env_streetlight_district_watt_bucket) b
LEFT JOIN env_streetlight_district_watt_bucket w
  ON w.district = d.district AND w.watt_bucket = b.watt_bucket AND w.city_scope = 'taipei'
ORDER BY b.watt_bucket_order, d.district
```

`query_type=three_d`, `map_config_ids={200}`, `city=taipei`, `time_from=static`

> `data` 為**燈數**（lamp_count）：BarPercentChart 以燈數比例計算各等級佔比；hover tooltip 顯示路燈數量（單位：盞）。
>
> 使用 CROSS JOIN 補齊所有行政區 × 所有瓦數等級組合（缺失補 0）。BE 的 `GetThreeDimensionalData` 按列順序組裝 series，若某行政區缺少某 bucket 的列，各 series 長度不一致，BarPercentChart 標籤與長條會錯位。

**Component B — metrotaipei：**

同上，`city_scope = 'metrotaipei'`, `map_config_ids={201}`, `city=metrotaipei`（同樣使用 CROSS JOIN）

### TPE ETL 流程（`streetlight_watt_tpe.py`）

1. `GET https://tppkl.blob.core.windows.net/blobfs/TaipeiLight.json`
2. 逐筆處理：
   - **行政區過濾與正規化**：`Dist` 欄位無「區」字尾（如「信義」），ETL 過濾非臺北市行政區後補上「區」（如「信義區」）再寫入
   - **watt 計算**：
     - 僅一種燈具（LightKind2..5 均空）：`watt = parse(LightWatt1) × Quantity`
     - 多種燈具：`watt = sum(parse(LightWatt1..5))`
     - `parse()` = 以 regex `[^\d.]` 替換為空字串後轉 float，失敗視為 0
   - **過濾**：`watt == 0` → 跳過
   - **分級**：依第 2 節規則指定 `watt_bucket` 與 `watt_bucket_order`
   - **座標轉換**：TWD97（EPSG:3826）→ WGS84（EPSG:4326），使用 `pyproj`
3. `TRUNCATE env_streetlight_assets_tpe` → bulk INSERT
4. 重建 `env_streetlight_district_summary`（`city_scope='taipei'`）：

   ```sql
   DELETE FROM env_streetlight_district_summary WHERE city_scope = 'taipei';
   INSERT INTO env_streetlight_district_summary (city_scope, district, avg_watt, lamp_count)
   SELECT 'taipei', district, ROUND(AVG(watt)::numeric, 1), COUNT(*)
   FROM env_streetlight_assets_tpe GROUP BY district;
   ```

5. 重建 `env_streetlight_district_watt_bucket`（`city_scope='taipei'`）：

   ```sql
   DELETE FROM env_streetlight_district_watt_bucket WHERE city_scope = 'taipei';
   INSERT INTO env_streetlight_district_watt_bucket
       (city_scope, district, watt_bucket, watt_bucket_order, total_watt, lamp_count)
   SELECT 'taipei', district, watt_bucket, watt_bucket_order,
          ROUND(SUM(watt)::numeric, 1), COUNT(*)
   FROM env_streetlight_assets_tpe
   GROUP BY district, watt_bucket, watt_bucket_order;
   ```

   > 採 DELETE + INSERT 而非 ON CONFLICT DO UPDATE，避免行政區異動時留下舊資料列。

### NTPE ETL 流程（`streetlight_watt_ntpe.py`）

1. 使用 `NewTaipeiAPIClient(RID, input_format="json").get_all_data(size=1000)` 分頁抓取（`page`/`size` 參數，共約 270 頁）
2. 逐筆處理：
   - **watt 計算**：`power` 欄位可能為逗號分隔多燈值（如 `130,130`），逐段解析後**加總**
   - **過濾**：`watt == 0` → 跳過
   - **分級**：同 TPE
   - 座標直接使用 `longitude` / `latitude`（已為 WGS84）
3. `TRUNCATE env_streetlight_assets_ntpe` → bulk INSERT
4. 重建 `env_streetlight_district_summary`（`city_scope='metrotaipei'`，合併兩市）：

   ```sql
   DELETE FROM env_streetlight_district_summary WHERE city_scope = 'metrotaipei';
   INSERT INTO env_streetlight_district_summary (city_scope, district, avg_watt, lamp_count)
   SELECT 'metrotaipei', district, ROUND(AVG(watt)::numeric, 1), COUNT(*)
   FROM (
     SELECT district, watt FROM env_streetlight_assets_tpe
     UNION ALL
     SELECT district, watt FROM env_streetlight_assets_ntpe
   ) combined GROUP BY district;
   ```

5. 重建 `env_streetlight_district_watt_bucket`（`city_scope='metrotaipei'`）：

   ```sql
   DELETE FROM env_streetlight_district_watt_bucket WHERE city_scope = 'metrotaipei';
   INSERT INTO env_streetlight_district_watt_bucket
       (city_scope, district, watt_bucket, watt_bucket_order, total_watt, lamp_count)
   SELECT 'metrotaipei', district, watt_bucket, watt_bucket_order,
          ROUND(SUM(watt)::numeric, 1), COUNT(*)
   FROM (
     SELECT district, watt, watt_bucket, watt_bucket_order FROM env_streetlight_assets_tpe
     UNION ALL
     SELECT district, watt, watt_bucket, watt_bucket_order FROM env_streetlight_assets_ntpe
   ) combined GROUP BY district, watt_bucket, watt_bucket_order;
   ```
