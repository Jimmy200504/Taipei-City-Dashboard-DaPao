### 欄位解讀

#### 臺北市欄位

臺北市一筆記錄代表一根燈桿（`watt` = 所有燈具瓦數加總）。座標為 TWD97，ETL 轉換為 WGS84（EPSG:3826 → EPSG:4326）。

| 欄位 | 說明 |
|------|------|
| `SerialNumber` | 路燈編號（主鍵） |
| `Dist` | 行政區 |
| `Quantity` | 燈桿燈數量 |
| `LightKind1`–`LightKind5` | 燈種（第 2–5 可空） |
| `LightWatt1`–`LightWatt5` | 對應燈種功率（需清理） |
| `LightHeight` | 燈桿高度（公尺） |
| `LightYear` | 裝設年分 |
| `TWD97X` / `TWD97Y` | TWD97 座標，需轉 WGS84 |
| `UpdDate` | 記錄更新日期 |

#### 新北市欄位

新北市一筆記錄代表一盞路燈，已提供 WGS84 座標，無燈種與裝設年分。

| 欄位 | 說明 |
|------|------|
| `seqno` | 路燈序號（主鍵） |
| `town` | 行政區 |
| `address` | 地址（部分含 `*` 遮蔽） |
| `power` | 瓦數字串（需清理） |
| `longitude` / `latitude` | WGS84 座標（直接使用） |
| `height` | 燈桿高度（多為空） |

#### 雙北欄位對照

| 概念 | 臺北欄位 | 新北欄位 |
|------|---------|---------|
| 路燈 ID | `SerialNumber` | `seqno` |
| 行政區 | `Dist` | `town` |
| 瓦數 | `LightWatt1–5`（多燈種） | `power` |
| 燈種 | `LightKind1–5` | 無（填 `unknown`） |
| 裝設年分 | `LightYear` | 無（填 `NULL`） |
| 座標 | TWD97 → 需轉換 | WGS84 直接使用 |

### 瓦數級距定義

| `watt_bucket` | `watt_bucket_order` | 規則 |
|---------------|---------------------|------|
| `ultra_low` | 1 | `watt <= 30` |
| `low` | 2 | `31 ≤ watt ≤ 80` |
| `medium` | 3 | `81 ≤ watt ≤ 150` |
| `high` | 4 | `151 ≤ watt ≤ 250` |
| `very_high` | 5 | `watt > 250` |
| `unknown` | 6 | 無法解析 |

### 圖表查詢

```sql
-- 行政區平均瓦數
SELECT district AS x_axis, ROUND(avg_watt, 1) AS data
FROM env_streetlight_district_summary
WHERE city_scope = 'taipei'   -- 或 'twin_city'
ORDER BY avg_watt DESC;

-- 瓦數級距占比
SELECT watt_bucket AS x_axis, light_count AS data
FROM env_streetlight_watt_bucket_summary

```

### 瓦數計算邏輯（臺北市）

- 一根燈桿 = 一筆地圖點位
- 僅一種燈具：`watt = LightWatt1 × Quantity`
- 多種燈具：`watt = sum(各 LightWatt)`（各種數量未提供，不乘）
- 無法解析：`watt = NULL`，`watt_bucket = 'unknown'`
